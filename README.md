# CS2 MOD Integrated GUI

Cities: Skylines II の MOD 関連データを扱うための統合GUIツールです。  
主に `PdxModsCache.json` を対象として、コピー・Excel変換・CSV変換を GUI 上で簡単に実行できます。

---

## Overview / 概要

This project is a standalone GUI tool for handling MOD-related data for Cities: Skylines II.  
It is designed to simplify copying, Excel export, and CSV export of `PdxModsCache.json`.

このプロジェクトは、Cities: Skylines II の MOD 関連データを扱うためのスタンドアロンGUIツールです。  
`PdxModsCache.json` のコピー、Excel変換、CSV変換をわかりやすく行えるようにしています。

---

## Main Features / 主な機能

- Copy `PdxModsCache.json`
- Export to Excel
- Export to CSV
- Save / restore previous paths
- Japanese / English UI switching
- Standalone EXE distribution

- `PdxModsCache.json` のコピー
- Excel出力
- CSV出力
- 前回パスの保存 / 復元
- 日本語 / English UI 切替
- スタンドアロン EXE 配布
